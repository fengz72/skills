# 原生编排、隔离与恢复

## 主控与角色

主控维护原生计划及 progress，统一用户交流、OPT 分配、设备调度与集成决定。SE、开发、测试按任务启动，可同角色多个实例；并发额度以实际宿主为准，不预设模型降级。子任务回传问题给主控，不再建立嵌套全局编排。

发现宿主能选择自定义角色时使用已注册角色；本包在 [assets/codex/agents](../assets/codex/agents/) 提供可选 TOML 模板，按目标项目的宿主配置方式接入，并由父任务提供实际 skill 根。不能选择时把 [角色正文](roles/se.md) 的具体路径与任务传给普通 subagent，并要求先读角色说明。不能声称 TOML 已加载，不能将 OpenCode 的 frontmatter 当作 Codex 配置。没有 subagent 能力时明确说明角色独立性受限，按当前授权可继续准备材料，但不将单 Agent 自测冒充独立验收。

## 派发内容

```text
角色、具体目标与依赖；design / progress / OPT 路径
基线与代码快照（含未提交修改）、实际工作副本、允许写入范围
实际主机、容器身份、project/run 目录、物理设备与共享锁目录
需要读取的本包 skill / reference
完成条件、实验/时间预算、命令/超时/取消约定
报告与原始结果位置、回传方式；运行后回传远端任务句柄/状态
```

子任务回“结论 + 报告路径 + 未决项”，报告给变更、命令/退出码、数据/版本/环境身份、指标和原始证据。按时回传尚在运行的任务句柄，不把本地调用返回当作远端完成。

## 并行与集成

只读分析可共享固定快照，各写独立报告；开发用实际执行主机上的独立 worktree 或等价副本，连同构建、缓存、临时和结果目录一起隔离。快照包含有效未提交变更和必要未跟踪文件，仅 HEAD 不足。固定大权重可以只读共享并记录身份。

主控指定开发将候选集成到当前目标版本，解决冲突并生成新快照，测试复验后再更新已采纳版本。主控不在测试快照上同时修改代码。progress 只有主控写，OPT 文档指定当前写者顺序交接。

## 实际设备与远端

每个物理设备在正式测量时排他使用；核预算、容器的逻辑编号和独立目录不代表设备独占。多容器必须共享同一个互斥位置并将可见编号映射为一致的物理身份；锁目录未共享或有不受协调的外部负载时，不宣称受控测量。

### 设备可用性门禁

在启动设备测试前，核查授权候选设备的实际占用、资源平台预约和本任务残留状态，记录时间、逻辑与物理设备映射、进程/作业身份以及可用性结论。设备工具可能只显示宿主 PID；容器内看不到该进程或瞬时 AICore 利用率为零，都不能据此认定设备空闲。

**所有授权候选 NPU 都被其他进程占用时，暂不进行性能测试。** 将性能阶段标记为“未运行：等待可独占设备”，继续需求设计、静态分析、离线验证和测量工具准备；不挤占其他任务，不终止他人进程，也不把共享负载下的观察写成正式性能基线。需要设备的正确性验证同样等待可用资源，已有历史结果保留原来的证据身份。

若仅部分设备空闲，只选择已确认可用且在授权范围内的设备。占用或释放状态无法确认时，维持待核查。用户或资源平台提供可用设备后，重新核对占用与预约、获得对应设备锁，再按阶段恢复；不跳过正确性或测量契约检查。

使用 [device-job 辅助](device-job.md) 在实际执行主机启动和取消前台任务。没有 NPU 探测插件时，辅助脚本只能证明受管进程状态，测试仍需核对真实设备占用/上下文。预先验证成功、超时、信号和断连路径；不可管理的后台 daemon 不属于辅助脚本的保证范围。

断开 SSH/停止子 Agent 不等于终止远端。按真实任务身份接管或取消，只处理本任务拥有的进程，不按进程名全局杀进程。身份、清理或设备释放无法确认时标记待核查，不解锁后立即发下一项。命令显式选择主机、容器、cwd，不依赖本地镜像或默认登录位置。

## 恢复与证据失效

恢复读取 progress、design、OPT 和必要报告，核对模型/数据/代码/配置/环境身份，再检查实际主机的旧任务。运行中则继续接管或按约定取消；已结束则核验退出码与必需结果；状态不明先核查，避免重复提交。原生会话恢复不保证旧 subagent 仍存活。

源模型、导出、编译依赖变化按需重建并验证；运行时缓冲、解析插件、自定义算子、前后处理、CANN/驱动等影响语义的变化重新验证相关功能和精度，不能只测性能。纯统计口径变化重测相应性能。输入/expected/阈值变化产生新验收身份。组合总是重新验收；报告文字修正不触发全量重跑。

不自动修改共享 skills 或发布模型/业务数据。新经验先写本项目；确认可共享范围后再整理随包案例和必要证据。
