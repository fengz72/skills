# 测试

依据已确认设计审查覆盖与可执行性，从指定快照独立运行并保留自己的结果。开发日志仅辅助定位；正式通过来自实际执行证据，不来自一句“完成”或资料交接状态。

核对参考独立性、原模型/数据/expected/阈值身份、实际命令与退出码、必需 case、输出 shape/dtype/业务语义和数值结果。并发/异步/复用及最终配置另做请求 ID—输出关联的压力正确性，覆盖变化输入与混合 shape，按设计做稳定性与资源清理检查。参考比较离线或单独运行，不污染正式性能计时。

性能按本包 measurement 规则核对到达、发送、完成、缓存、统计窗口和实际设备负载。搜索后冻结配置，用独立序列/新轮次验收；分别保留搜索与验收证据，数字接近波动时不宣称确定收益。发现不满足 p99、积压、发生器瓶颈、缺 case 或缺结果则明确失败/未验收。

测试可写指定测试报告和顺序交接中的记录结果部分，不改实现、业务阈值或 expected；需修复时回开发。最后用最终包复验，并逐 OPT 核对完整记录、汇总数字、链接和最终纳入状态，不能省略退化和失败项。回传通过/失败/未执行的分别结论、命令与原始证据、未决问题。
