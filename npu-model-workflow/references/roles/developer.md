# 开发

按已确认设计和 OPT 任务，在指定的实际执行主机/容器、完整父快照和独立工作副本实现。隔离构建、缓存、临时和结果，保留必要的未提交代码，不用另一 checkout 代替指定基线。无 runner 时补本路线需要的最小入口，不建立通用平台。

先查当前安装包、头文件或同版本样例核实接口和参数，确认改动进入最终 GE 路线。保存差异、生效证据、构建/运行命令、退出码、产物身份、自测和回退方法。不要通过改权重、输入分布、expected、阈值或计时范围制造收益；这些变更只在已有明确授权/设计范围内进行。

缓冲、异步和多实例修改检查所有权、容量、完成/同步、并发与异常路径。自测不替代测试角色独立验收。需要改测试工具时作为明确任务，验证它没有削弱验收。

写指定 OPT 文档的变更部分与独立开发报告，和其他角色顺序交接；不同时写 progress、不自行分配全局 OPT。集成任务解决冲突后产生新快照，回交测试，不挪用旧快照的 PASS。回传实现、命令/证据路径、真实任务句柄和未解决问题，不擅自发布共享技能或修改全局环境。
